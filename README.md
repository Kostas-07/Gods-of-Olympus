# Οι 12 Θεοί του Ολύμπου

Παιχνίδι γνώσεων σε HTML, CSS και JavaScript.

## Εκτέλεση
Άνοιξε το `index.html` με έναν browser (Chrome, Edge ή Firefox).

## Αρχεία
- `index.html`: δομή της εφαρμογής
- `style.css`: εμφάνιση
- `script.js`: ερωτήσεις και λειτουργία του παιχνιδιού

## Κανόνας
Κάθε θεός έχει 5 ερωτήσεις. Ο παίκτης χρειάζεται 5/5 για να προχωρήσει στον επόμενο θεό.
